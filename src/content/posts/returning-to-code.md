# Returning to Code: Finding My Way Back

It's been roughly three months since I've consistently pushed code to GitHub.

Life happened. Between recovering from an injury, keeping up with school, and dealing with everything else, programming gradually moved further down my priority list.

But my interest in software engineering and artificial intelligence never disappeared.

Now I'm finding my way back.

## Where I Left Off

Before my break, I was exploring AI engineering, building autonomous agent systems, and experimenting with full-stack applications.

Some of my projects include:

- **Recuris:** An autonomous AI software development system.
- **TaahirahOS:** An interactive portfolio inspired by retro operating systems.
- **AI experiments:** Exploring local language models, developer tools, and automation.

There are unfinished features, bugs to fix, and plenty of ideas I haven't explored yet.

## Starting Again

My first step back is rebuilding my portfolio.

I'm using React, TypeScript, Vite, and Tailwind CSS to create a personal website that better reflects who I am as a developer.

I'm also adding this blog to document what I'm building, what I'm learning, and the problems I encounter along the way.

## What's Next?

I have three goals:

1. Finish and publish my new portfolio.
2. Revisit my existing projects and decide what to work on next.
3. Document my progress instead of focusing on my GitHub contribution graph.

I don't need to write code every single day to prove I'm a developer.

I want to build things that matter to me, understand the technology behind them, and become a stronger engineer in the process.

This blog is where I'll document that journey.

**Welcome to Vector Nomad.**
